SOUNDCLOUD // OPTIONAL CONNECTION

Checking connection…

SoundCloud is an optional alpha feature. Song Request can use it for playable track searches, official widget playback, and playlist imports after this connection is ready.

What you need

SoundCloud requires each server owner to use their own registered developer app. RaveLink never displays a saved secret again.

  1. Sign in to SoundCloud and make sure the account has Artist Pro.
  2. Open SoundCloud’s app registration page and register an app. If SoundCloud asks for a website or redirect address, use your own project/site information; RaveLink uses server-to-server access and does not need listeners to sign in.
  3. In the new app’s credentials, copy both the Client ID and Client Secret.
  4. Open “Developer credentials” below, paste both values, and choose Save. You only do this once unless SoundCloud replaces the credentials.
  5. Open Song Request. Choose SoundCloud for individual requests, or paste a public SoundCloud playlist URL in Server Playlists.

SoundCloud calls these “developer” credentials. You do not need to enable RaveLink’s global developer mode.

Developer credentials

The values are write-only. On Windows they are encrypted for this Windows account. They are never added to exports, release files, or the public repository.
