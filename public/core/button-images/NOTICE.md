# Scene button artwork

Reusable generic scene artwork, created for RaveLink. These files contain no scene bindings or account settings. The gaming, desktop, camera, close-up, cinema and cooking illustrations incorporate Lucide 1.70.0 paths under the ISC/MIT terms in ../button-icons/LICENSE.txt. Creature-ball and handheld geometry is first-party RaveLink artwork. PNG files are rendered from the adjacent SVG sources.
