DYNAMIC COLOR COMMANDS

                

                  Let viewers run color patterns and spatial effects with
                  cycle, fade, breathe,
                  rainbow, wave, sweep,
                  ripple, chase, or audio-reactive
                  rave. Spatial commands use saved room positions. Enable Allow
                  rave and select an audio source in Music to let viewers start Rave through the
                  Change Lights channel-points reward. Use rave,
                  rave red, blue aggressive, or rave stop. Other viewer
                  light changes are refused while Rave is active. For other effects, a new static
                  color ends the session: selected fixtures take the new color and its other
                  fixtures return to their previous lighting.
                

                
                
                

                  The return animation uses each fixture’s last state from this server session,
                  including RGB, brightness, and white mode. Fixtures without a known previous state
                  simply stop.
                

                

                  ALL means all fixtures routed in the relevant program. Unrouted
                  and disabled fixtures remain untouched.
                

                

                  
FIXTURES ALLOWED TO RUN EFFECTS

                  

                    Dynamic routing is independent from the normal color-command board above.
                    Commands without a prefix affect every enabled fixture. Optional fixture
                    prefixes select smaller subsets, and fixtures sharing a prefix run together.

                  Recipe, color roles & timing
                  

                    
                    
                    
                    
                    
                    
                    
                    
                  

                  

                    One complete recipe is chosen and locked when activated. Audio drives its
                    response; it never chooses or changes the recipe. Artistic edits apply to the
                    next activation. Blocking a selected layer or scenario ends the current recipe
                    and restores its lights. Rave also needs granted audio access, a selected source
                    and allowed music lights. Rave draws one scenario and optional layers once per
                    request, or follows your pinned choices. Blocked layers are never drawn. The
                    Preview / Go Live mode is separate. Song timing ends at the current song's end;
                    with one minute or less remaining, it covers the following song too. Pauses hold
                    the song timer. Missing timing uses the dynamic-effect timer (or the default
                    above when unset). Separate music timer uses the seconds above instead. Lost
                    song timing falls back to a finite timer. Every song effect has a 30-minute
                    safety limit.
                  

                

                

                

                  Measured levels will appear during Preview or Live.
                

                

                

                  Allowed scenarios & chances
                  

                    Uncheck a scenario to forbid it. Weights alone set the draw; audio never
                    influences the choice. Equal weights give equal chances. The displayed draw
                    stays fixed for this request. New weights affect the next request; blocking the
                    active scenario ends it and restores the previous lighting owner.

                Calibration & output settings
                
                

                  The highest output your lights may use. Intensity stays within this limit.
                

                
                

                  Play a representative passage at your usual comfortable volume. Calibration
                  captures the selected source in Preview, never changes playback volume and never
                  controls lights. It sets a fixed reference; quiet passages stay quiet.
                

                

                  
                    Calibration options · 30 seconds with 3 dB headroom
                  
                  

                    
                    
                  

                  

                    Include both quieter and louder passages. A short quiet sample can make later
                    music sit at the ceiling and lose detail. If calibrated loudness stays at 100%,
                    use a longer sample or more headroom. The reference stays fixed after
                    calibration.
                  

                

                

                

                  If changing app volume changes the captured meter, recalibrate. Automatic volume
                  compensation requires a verified gain reading; headphone loudness cannot be
                  inferred from a volume percentage.
                

                

                  
                  
                

                

                  Hue Entertainment uses the selected rate after connection preheat. Hue REST shares
                  an 8-command/second budget. WiZ can update independently up to the selected rate.
                  Adaptive output uses 2–8 Hz for calibrated energy, 12 Hz for rises and up to 16 Hz
                  for strong rises or attacks, capped by your selection. The fast-rate hold prevents
                  chatter. Slow writes drop intermediate frames instead of building a backlog. These
                  are requested rates, not guaranteed physical bulb refresh rates.

LED STRIP SECTIONS

                

                  Section prefixes will appear only after an installed transport proves that it can
                  address segments independently.
                

              

              CAPABILITY-GATED
            

            

              

                HUE GRADIENTRequires Hue Entertainment API v2. The current v1-compatible stream can control
                  only the full fixture.
              

              

                GOVEE SEGMENTSAvailable through Govee's credentialed cloud capability on supported models. The
                  current private LAN adapter controls the full fixture.
              

              

                WIZ DUAL ZONEWiZ exposes a zone ratio, not independently colored addressable sections.
              

            

            

              RaveLink will not create section prefixes that silently recolor the complete strip.
              When a segment-capable transport is added, sections can be grouped, locked together,
              and routed through the same chat-prefix system.
