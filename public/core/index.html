OPTIONAL LOCAL DEVICE SUPPORT
GOVEE LAN
ALPHA
            
RaveLink controls compatible Govee lights directly over your home network. No Govee cloud password or API key is needed.

            
  1. Open the Govee Home app and select a light.
  2. Open that light's settings and turn on LAN Control. Repeat this for every light you want to use.
  3. Keep this computer and the lights on the same network, then select Find Govee Lights.

            

            
Compatibility and troubleshooting
Only Govee models that expose LAN Control can be discovered. If nothing appears, confirm the light is powered on, LAN Control is enabled, and your router does not isolate wireless devices from this computer.
