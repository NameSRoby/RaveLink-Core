DYNAMIC COLOR COMMANDS

                

                  Let viewers run color patterns and spatial effects with
                  cycle, fade, breathe,
                  rainbow, wave, sweep,
                  ripple, chase, or audio-reactive
                  rave. Spatial commands use saved room positions. Enable Allow
                  rave and select an audio source in Music to let viewers start Rave through the
                  Change Lights channel-points reward. Use rave,
                  rave red, blue aggressive, or rave stop. Other viewer
                  light changes are refused while Rave is active. For other effects, a new static
                  color ends the session: selected fixtures take the new color and its other
                  fixtures return to their previous lighting.
                

                
                
                

                  The return animation uses each fixture’s last state from this server session,
                  including RGB, brightness, and white mode. Fixtures without a known previous state
                  simply stop.

                  and disabled fixtures remain untouched.

                OPTIONAL LOCAL DEVICE SUPPORT
                
    GOVEE LAN
    
              
    
              COMPATIBLE LAN MODELS
                
            
    
              RaveLink controls compatible Govee lights directly over your home network. No Govee
              cloud password or API key is needed.
            
    
            
    
              Features depend on your fixture and firmware. LAN Control must be available and
              enabled. Music, Rave, chat effects and profiles control the whole light; segments,
              DreamView and Govee app scenes are not exposed by this LAN connection. White color
              temperature only works on fixtures that support it. Stop restores the reported power,
              brightness and RGB or white state; an app animation cannot be recreated because LAN
              status does not report its scene. Music output is limited to eight updates per second,
              so very short pulses may look softer than Hue Entertainment.
            
    
            
      
              
    1. Open the Govee Home app and select a light.
      2.

                LAN Control. Repeat this for every light you want to use.

    3.

              Compatibility and troubleshooting

                isolate wireless devices from this computer.
